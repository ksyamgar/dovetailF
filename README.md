# Dovetail Architecture — Himalayan Practice & Digital Portfolio

![Next.js](https://img.shields.io/badge/Next.js-14.x-black?style=flat-square&logo=next.js) ![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=flat-square&logo=typescript&logoColor=white) ![License](https://img.shields.io/badge/License-Proprietary-gray?style=flat-square)

An architectural website and interactive digital cartography platform for **Dovetail Architecture**, an architectural practice led by **Ar. Karan Sharma (M.Arch CEPT)** specializing in conservation, adaptive reuse, residential, interior, and landscape interventions across the Western and Central Himalayas.

Built with a minimalist aesthetic inspired by vernacular Himalayan material culture and contemporary architectural practices — featuring crisp typography, micro-animations, a custom architectural compass cursor, and interactive spatial mapping of the Himalayan range.

---

### Key Features

#### 1. Dynamic Projects Portfolio
- **Immersive View Modes**: Toggle seamlessly between immersive large thumbnails, dense structural grids, and sleek architectural list views.
- **Multimedia Integration**: Seamless ambient video headers with synchronized carousels and direct architectural navigation.
- **Intelligent Filtering**: Fluid client-side state filtering for typologies spanning Residential, Heritage, Hospitality, and Master Planning.

#### 2. Auto-Drafting Enquiry System
- **Preset-Driven Engine**: A scalable, dynamic contact form that synthesizes architectural briefs in real time.
- **Instantaneous Formatting**: Users select parameters (Typology, Budget, Timeline, Region) and the engine auto-drafts a professional, contextual message.
- **Multi-Branch Logic**: Supports unified workflows for Project Commissions, Media Features, Partnerships, and Careers.

#### 3. Interactive Cartography
- **Himalayan Topography**: Custom Leaflet integrations mapping Dovetail's regional presence across elevations up to 3,500m ASL.
- **Studio Coordinates**: Visual pinning of the Palampur Headquarters, Ladakh Field Studio, Chandigarh, and Kathmandu bases.

#### 4. High-Performance Architecture
- **Next.js App Router**: Server-side rendering guarantees exceptional performance despite high-resolution architectural photography.
- **Custom Design System**: Modular CSS tailored to structural grid systems, hairline borders, and earth-toned transparency effects.

- **Core Engine:** Next.js (App Router)

### Getting Started

#### Prerequisites
- Node.js (v18+)
- npm or yarn

#### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ksyamgar/dovetailF.git
   cd dovetailF
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3123](http://localhost:3123) in your browser to view the digital platform.
